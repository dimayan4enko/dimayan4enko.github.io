claude-sheets

A personal command-line tool for working with my own Google Sheets.

What it does

claude-sheets is a private, single-user utility. It uses the Google Sheets API to read and write spreadsheets belonging to the person who signs in — mainly to inspect and repair spreadsheet formulas that are tedious to edit by hand.

Who it is for

It is not a public service and has no user accounts of its own. It runs locally on the owner's computer via the gws command-line tool.

Data access

The application requests a single OAuth scope, https://www.googleapis.com/auth/spreadsheets, which allows it to read and edit spreadsheets in the signed-in account. It does not request access to Gmail, Drive, Calendar, Contacts, or any other Google service.
